# Unity-BallGame
Simple ball game for a school assignment. The main objective is to collect all the coins in the maze while avoiding red kill bricks. There are total of 3 levels which increase in difficulty.

### How to build the game yourself?
Since its a Unity game you need to [install](https://cloud.unity.com/home/organizations/5773926382149/onboarding/post-download) Unity to your computer <br>
When opening the project in Unity go to File -> Build settings (select all scenes) -> Build
